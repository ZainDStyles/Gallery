# Gallery: Zain's public demo sites

This public repo is hosted free on GitHub Pages. Each folder is a demo you can send to a business as a link.
Demos only: names, numbers, prices and reviews in them are placeholders.

| Demo | Link | For |
| --- | --- | --- |
| Atelier hair salon | https://zaindstyles.github.io/Gallery/salon/ | Hairdressers |
| Aurum Motor Oil (scroll-to-pour hero + shop) | https://zaindstyles.github.io/Gallery/aurum-motor-oil/ | Car oil, garages, servicing |
| Photo gallery (old) | https://zaindstyles.github.io/Gallery/ | The original photo page (root `index.html` + `images/`) |

Other demos live in their own repos (see each README): hairdresser-demo, lacquer-detail (car detailing).

## Adding a demo
Put it in its own folder with an `index.html` and relative paths. Push to `main` and it's live in about a minute.
