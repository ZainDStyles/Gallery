# Gallery

## Design engineering skills

Emil Kowalski's skills (https://github.com/emilkowalski/skills, commit e8a175d, MIT) are installed in `.claude/skills/`.

When building or improving UI in this repo, use them:

- Building or polishing any UI: `emil-design-eng`
- Adding or fixing animation/motion: `animate` (critique: `review-animations`, audit: `improve-animations`, ideas: `find-animation-opportunities`)
- Phone/touch behaviour: `mobile-native`
- Stress-testing with edge-case data: `break-ui`
- Explicit-only: `prototype`, `pick-ui-library`

Not relevant to this static site: `animate-expo`, `write-swift`, `ask-sonner`.
