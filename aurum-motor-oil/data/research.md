# Oil research (31 Oct 2026)

Specs come from web-search extracts of maker and retailer pages. Some sites (halfords.com, msdspds.castrol.com) could not be opened
directly, so check each bottle's own label before going live. Prices are snapshots of unknown date and are only examples.

## Castrol EDGE 5W-30 LL
- ACEA C3. API SQ appears on Halfords and Amazon listings only, so it's left off the site.
- Approved: VW 504 00 / 507 00, BMW Longlife-04, MB 229.31 / 229.51, Porsche C30.
- A 2025 Castrol sheet lists different MB/VW codes (MB 229.31, VW 505 00/505 01), so approvals may differ by batch.
- Prices: 1 L £15.99, 4 L £39.99 (Halfords). 5 L sold at Costco, GSF, Euro Car Parts; price unconfirmed.
- Sources: castrol.com/en_gb/united-kingdom (5W-30 page); Castrol PDS bpxe-bk36lm.pdf and wepp-c638pb.pdf; Halfords 252023, 251215; Amazon B0C8154V2R; Euro Car Parts 521774532; GSF; Costco 374262.

## Castrol MAGNATEC 5W-30 A5
- ACEA A5/B5, API SP, ILSAC GF-6 (newest sheet). Older batches show A1/B1 + A5/B5, API SN, GF-5.
- Meets: Ford WSS-M2C913-D (Halfords and Castrol UK also list -A/-B/-C).
- One Castrol sheet and several retailers say it's not for cars with a diesel particulate filter.
- Prices: 1 L £14.99 (Halfords), 5 L £45.99 (Amazon).
- Sources: Castrol PDS wepp-dbdp4x.pdf, wepp-dc5f4y.pdf; Halfords 918672, 918805; Amazon B0C814DZ9D, B0C8139YWS; Euro Car Parts 521773420.

## Comma Syner-G 5W-40
- "Synthetic technology" (Comma's wording). ACEA A3/B4, API SN/CF.
- Approved: VW 502 00, VW 505 00, MB 229.3. Meets: MB 229.1, MB 226.5, Renault RN0700/RN0710.
- Porsche A40 appears on Comma's 5 L listing and GSF only. BMW LL-01 appears in third-party catalogues only. Both left off.
- Prices: 1 L £15.99, 5 L £45.99 (GSF).
- Sources: commaoil.com product page and TDS; GSF ZA042826, ZA042828; Arnold Clark SYN1L.

## Carlube Triple R 5W-30 Fully Synthetic Ford
- ACEA A5/B5, API SP. Same spec as the trade line R-TEC 17.
- Meets: Ford WSS-M2C913-D (Carlube: "meet and exceed"), -A/-B/-C, JLR STJLR.03.5003, Renault RN0700. No official Ford approval number found.
- Carlube claims more than 3% fuel economy in the CEC M111 test.
- Prices: 1 L £11.99 (Amazon), 4 L £32.99 (The Range, B&Q).
- Sources: carlube.co.uk; Rapid 95-3187; ManoMano; Amazon B01N3JIZDI, B0CBQ21CV2; The Range p344221; B&Q 5010373208892; MyMotorWorld KBL005.

## Carlube Triple R 5W-30 Fully Synthetic VW
- ACEA C3, API SN (some newer listings say SP). Low SAPS (Carlube). Same spec list as R-TEC 22. Not R-TEC 19.
- Meets: VW 504 00/507 00 (no official VW reference found), BMW LL-04, MB 229.31/229.51, Porsche C30.
- Prices: 1 L £14.99 (The Range), 5 L £34.99 (Carlube's own shop, R-TEC 22).
- Sources: carlube.co.uk (1 L and 5 L pages); Rapid 95-3189; B&Q 5010373119952; Amazon B01M6DGNW1, B0CBQ439SW, B0CBQ3MKMT; The Range; MyMotorWorld KFI005.

## TotalEnergies Quartz 9000 5W-40
- "Synthetic technology" (TotalEnergies). ACEA A3/B4, API SP/CF.
- Approved: MB 229.5, VW 502 00/505 00, BMW LL-01, Porsche A40, Renault RN0700/RN0710, Stellantis FPW9.55535/10.
- Not the same as Quartz 9000 ENERGY or FGO 5W-40.
- Prices: 1 L £14.99, 5 L £39.99 (Halfords).
- Sources: lubricants.catalog.totalenergies.com (714); totalenergies.co.uk; Halfords 224475, 224467; Amazon B002SQZ0Q8, B002SPH7BK.

## TotalEnergies Quartz INEO Long Life 5W-30
- Fully synthetic, low SAPS. ACEA C3, API SP (UK catalogue).
- Approved: VW 504 00/507 00, BMW LL-04, MB 229.31/229.51/229.52, Porsche C30. Meets: VW 505 00/505 01.
- An "OV 040 1547" approval appears in the Amazon title only; left off.
- Prices: 1 L £15.99, 5 L £44.99 (Halfords).
- Sources: lubricants.catalog.totalenergies.com (6e5); Halfords 224379, 224387; Amazon B006XEFO4O.

## Redex 5W-30 Fully Synthetic for BMW, VX, VW, MB (RMTN0009A)
- ACEA C3, API SN/CF. Holts' wording is "recommended for", so everything is "Meets".
- Meets: BMW LL-04, GM dexos2, MB 229.31/229.51/229.52, VW 505 00/505 01. Not VW 504 00/507 00.
- Only a 2 L bottle found: £19.49 (Toolstation).
- Redex also sells a separate "for VW, BMW, MB, P" bottle (RMTN0010A) with VW 504/507. Check which one you stock.
- Sources: holtsauto.com; Toolstation AF914; The Range p75320; Amazon B094DFX4P9.
